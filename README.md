# 🚀 Space Tech EDA Project

This project performs Exploratory Data Analysis (EDA) on space mission data using Python.

## 📌 Features
- Statistical Summary
- Correlation Analysis
- Missing Value Check
- Data Visualization
- Insights Generation

## 📊 Visualizations Used
- Bar Chart
- Scatter Plot
- Pie Chart

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
  
## 🎯 Project Objective
The main objective of this project is to analyze:
- Mission costs
- Success rates
- Number of launches
- Performance of space organizations

## 🚀 Organizations Included
- ISRO
- NASA
- SpaceX
- Roscosmos
- ESA

## 📌 Outcome
This project helps understand the basics of:
- Exploratory Data Analysis
- Data Visualization
- Space mission trend analysis
